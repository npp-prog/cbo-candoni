B. ANG WALA KO GIN-ILIS, KAG NGAA
---------------------------------------------------------------------------

Lima ka butang ang ginbilin ko nga "cbo". Hungod tanan.

   1. ANG ADDRESS: cbo.mgocandoni.com

      Amo ini ang ginpili mo. Ang ngalan sa screen CFMS na, pero ang
      address magapabilin. Wala sing DNS nga gintandog, wala sing
      downtime, kag ang bookmark sang tanan nagaobra gihapon.

      Kon gusto mo sia ilisan sa ulihi, bulag nga buluhaton ina kag
      himuon ko ang sunod-sunod nga instruksyon.

   2. ANG FOLDER: cbo-candoni

      Amo man ang ginpili mo. Internal lang sia, kag ang tanan nga
      runbook nga ginsulat na nagaobra gihapon.

   3. ANG FIREBASE PROJECT ID: cbo-candoni-dev / cbo-candoni-prod

      INDI GID INI MAILISAN. Permanente ang project ID sa Firebase -
      wala sing paagi nga mailisan sia, bisan sang Google. Ang bugtong
      nga paagi amo ang paghimo sang BAG-O nga project kag pagbalhin
      sang bug-os nga database, kag indi gid ina dapat himuon para sa
      ngalan lang.

   4. ANG FIREBASE CODEBASE: "cbo"

      ANG PINAKAIMPORTANTE DIRI. Ang `firebase.json` may linya nga
      "codebase": "cbo", kag amo ina ang rason nga ang deploy command
      naton amo ang:

         firebase deploy --only functions:cbo:postRcd

      Kon ilisan ko sia sa "cfms", ang Firebase MAGAHUNAHUNA NGA
      BAG-O NGA CODEBASE INA. Ang buot silingon: panason ang TANAN nga
      daan nga function, kag himuon tanan liwat. Sa sulod sina nga
      tion, ANG APP INDI MAKAOBRA.

      Para sa ngalan lang, indi ina angay. Gani nagpabilin sia nga
      "cbo", kag ang tanan nga deploy command nga ginagamit mo
      nagapabilin nga pareho.

   5. ANG MGA CSS CLASS: cbo-td, cbo-th, cbo-label, kag anom pa

      Ginagamit sila sa ginatos ka lugar sa sulod sang code, kag wala
      gid sing nagakakita sa ila luwas sa browser. Kon ilisan ko sila
      kag may isa nga malipatan ko, may bahin sang screen nga magawala
      ang porma - kag amo ina nga klase sang sala nga makita lang kon
      may mag-print na sang report.

      Wala sing makuha, may madula. Gani ginbilin ko sila.

D. PAG-INSTALL - LAIN SA KINAANDAN, BASAHA ANAY
===========================================================================

Ang zip may sulod nga BUG-OS NGA SOURCE, indi pila lang ka file.

NGAA: 158 ka file ang nagbag-o. Ang paglista sang 158 ka file kag ang
pagkopya isa-isa amo ang paagi nga may malipatan, kag ang resulta isa
ka app nga ang iban nga bahin CFMS kag ang iban CBO.

ANG INDI MATANDOG - importante ini:

   * node_modules     - wala sa zip, wala matandog
   * dist             - wala sa zip, wala matandog
   * .env.local       - WALA GID SA ZIP. Ang password kag key mo
                        nagapabilin. (.env.example lang ang ara, nga
                        template kag wala sing sekreto.)
   * .git             - wala sa zip

Gani WALA KA SING I-SETUP LIWAT. Wala ka sing i-type liwat nga key.

ANG LAKAT:

   1. Buksi ang patch59.zip.

   2. Sa sulod may mga folder: src, functions, docs, scripts, public,
      data, kag mga file sa gwa (package.json, index.html, kag iban
      pa).

   3. Kopyaha ang TANAN nga sulod sang zip pakadto sa root sang
      cbo-candoni folder.

   4. Kon mamangkot kon ilisan, pislita ang "Replace" ukon
      "Yes to All". DAPAT GID ILISAN TANAN.

   5. WALA SING PANASON NGA FILE.

---------------------------------------------------------------------------
E. PAG-BUILD
---------------------------------------------------------------------------

   1. PowerShell sa cbo-candoni folder.

   2. I-type, dayon Enter:

         $env:FUNCTIONS_DISCOVERY_TIMEOUT = "120"

   3. I-type, dayon Enter:

         npm run build

   4. I-type, dayon Enter:

         npm test

      Dapat 845 ka test - EKSAKTO NGA PAREHO sang patch 58. Kon lain
      ang numero, may sala sa pagkopya; sugiri ako.

   5. I-type, dayon Enter:

         node scripts/check-rules.mjs

      Dapat "All security rule checks passed."

   6. Dayon ang normal nga pag-upload sa Netlify.
